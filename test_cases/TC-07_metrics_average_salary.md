# TC-07 — Метрика «Средняя зарплата»

**Приоритет:** High
**Тип:** Функциональное
**Связанные баги:** BUG-07

## Шаги

1. Собрать вакансии по запросу «Python»
2. Посмотреть метрику «Средняя зарплата (от)»
3. Прочитать сноску под метриками
4. Навести курсор на метрику

## Ожидаемый результат

- Формат зарплаты — с пробелом: «150 000 ₽» (не «150,000 ₽»)
- Сноска показывает: «* Средняя зарплата рассчитана только по N из M вакансий...»
- Tooltip при наведении показывает то же самое
- Значение не равно 0, если есть вакансии с зарплатой
