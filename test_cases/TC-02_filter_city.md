# TC-02 — Фильтр по городу

**Приоритет:** High
**Тип:** Функциональное

## Шаги

1. Собрать вакансии по запросу «Python» (2 страницы)
2. В поле «Город» ввести «Москва»
3. Наблюдать результат

## Ожидаемый результат

- Список вакансий сокращается
- В карточках поле «Город» содержит «Москва»
- Метрика «Городов» = 1
- Счётчик «Найдено N» обновляется

## Проверка edge-кейсов

- Пустое поле «Город» — фильтр не применяется
- Ввод «москва» (нижний регистр) — работает
- Ввод «МОСКВА» (верхний регистр) — работает
- Ввод «Городкоторогонет» — список пустой, отображается «Нет вакансий»
