# TC-03 — Фильтр по уровню / опыту

**Приоритет:** High
**Тип:** Функциональное

## Шаги

1. Собрать вакансии по запросу «QA»
2. В селектбоксе «Уровень / Опыт» выбрать «Junior»
3. Наблюдать результат

## Ожидаемый результат

- Все вакансии в списке имеют бейдж «Junior»
- Счётчик обновляется
- При выборе «Все» возвращается полный список

## Проверка вариантов

- «Junior» — вакансии с бейджем Junior
- «Middle» — вакансии с бейджем Middle
- «Senior» — вакансии с бейджем Senior
- «1-3 года» — вакансии с этим уровнем
- «3-6 лет»
- «Более 6 лет»
- «Не указан»
