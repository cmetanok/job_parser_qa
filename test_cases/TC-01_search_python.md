# TC-01 — Поиск вакансий по ключевому слову «Python»

**Приоритет:** Critical
**Тип:** Функциональное
**Предусловие:** Приложение запущено

## Шаги

1. Открыть приложение
2. В поле «Ключевое слово» ввести «Python»
3. В «Источники» выбрать «Habr Career» и «Trudvsem»
4. Установить «Страниц для парсинга» = 2
5. Нажать «Собрать вакансии»

## Ожидаемый результат

- Появляется сообщение «Собираем вакансии...»
- Через 5–15 секунд отображается «Найдено N вакансий», N > 0
- Метрика «Всего вакансий» = N
- Метрика «Средняя зарплата» > 0
- В карточках видны бейджи «Habr Career» и/или «Trudvsem»
- Таблица топ-навыков содержит «Python»

## Фактический результат

Pass — тест пройден успешно.
