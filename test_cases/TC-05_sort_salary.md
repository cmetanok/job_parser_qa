# TC-05 — Сортировка по зарплате

**Приоритет:** Medium
**Тип:** Функциональное

## Шаги

1. Собрать вакансии по запросу «Python»
2. В «Сортировать» выбрать «По зарплате (убывание)»
3. Проверить порядок
4. Выбрать «По зарплате (возрастание)»
5. Проверить порядок

## Ожидаемый результат

- Убывание: первая вакансия имеет максимальную зарплату
- Возрастание: первая вакансия имеет минимальную зарплату
- Вакансии без зарплаты уходят в конец списка
