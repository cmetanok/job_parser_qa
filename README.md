# Job Parser — QA-документация

Репозиторий содержит документацию по ручному тестированию веб-приложения [Job Parser](https://jobparser-ej3bytqpnvzmwpgn5t4x46.streamlit.app/) — дашборда для анализа вакансий с Habr Career и Trudvsem.

## Что внутри

- **Тест-план** - стратегия и объём тестирования
- **Чек-листы** - функциональность, UI, парсеры
- **Тест-кейсы** - 8 сценариев с шагами и ожидаемыми результатами
- **Баг-репорты** - 8 дефектов, найденных в процессе разработки и тестирования
- **Автотесты** - 25 тестов на pytest, покрывающих парсеры и валидацию данных
## Тестируемое приложение

- **Ссылка:** https://jobparser-ej3bytqpnvzmwpgn5t4x46.streamlit.app/
- **Исходный код:** https://github.com/cmetanok/job_parser
- **Стек:** Python, Streamlit, Pandas, Plotly
- **Источники данных:** Habr Career API, Trudvsem API
