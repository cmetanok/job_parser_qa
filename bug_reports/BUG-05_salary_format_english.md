# BUG-05 — Средняя зарплата отображается в англоязычном формате

**Приоритет:** Medium
**Severity:** Minor
**Статус:** Fixed

## Шаги воспроизведения

1. Собрать вакансии
2. Посмотреть метрику «Средняя зарплата»

## Ожидаемый результат

Формат «150 000 ₽» (разделитель тысяч — пробел).

## Фактический результат

Формат «150,000 ₽» (разделитель — запятая).

## Причина

Python по умолчанию использует запятую как разделитель тысяч в `f"{value:,}"`.

## Исправление

Добавлена замена: `f"{value:,}".replace(",", " ")`.
