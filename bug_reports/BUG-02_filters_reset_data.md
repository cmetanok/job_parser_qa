# BUG-02 — Данные пропадают при изменении фильтров

**Приоритет:** Critical
**Severity:** Blocker
**Статус:** Fixed

## Шаги воспроизведения

1. Собрать вакансии по запросу «Python»
2. Изменить любой фильтр (источник, город, грейд)
3. Наблюдать результат

## Ожидаемый результат

Список вакансий фильтруется, данные остаются.

## Фактический результат

Список исчезает полностью. Появляется сообщение «Настройте параметры в сайдбаре...».

## Причина

Streamlit перезапускает скрипт при каждом взаимодействии с виджетом. Переменная `df` не сохранялась между перезапусками — блок `if search_button:` пропускался, и фильтры применялись к пустоте.

## Исправление

DataFrame сохраняется в `st.session_state["df"]` после сбора данных. Отображение работает с `st.session_state`, а не с локальной переменной.
