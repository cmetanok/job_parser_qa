# BUG-03 — Фильтр «Только удалёнка» возвращает пустой список

**Приоритет:** High
**Severity:** Major
**Статус:** Fixed (частично)

## Шаги воспроизведения

1. Собрать вакансии по запросу «Python»
2. Поставить галочку «Только удалённая работа»
3. Наблюдать результат

## Ожидаемый результат

Остаются только удалённые вакансии.

## Фактический результат

Список пустой, хотя в данных есть вакансии с пометкой «Можно удалённо».

## Причина

Поле `remote` в API Habr Career часто отсутствует или равно `False`, даже если вакансия помечена как удалённая. Фильтр `filtered["remote"] == True` отсеивал всё подряд.

## Исправление

1. Добавлена проверка HTML-страницы вакансии на маркеры «можно удалённо», «удалённо», «remote».
2. Фильтр в `app.py` теперь нормализует значения: `bool(x)` или проверка строки на `true`/`1`/`yes`/`да`.

## Остаточный риск

Не все удалённые вакансии помечаются корректно — API источника не всегда отдаёт явный признак.
