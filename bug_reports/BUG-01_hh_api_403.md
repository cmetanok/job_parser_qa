# BUG-01 — hh.ru API возвращает 403 Forbidden

**Приоритет:** High
**Severity:** Major
**Статус:** Won't Fix (внешнее ограничение)

## Окружение

Windows 11, Chrome 120, Python 3.13

## Шаги воспроизведения

1. Открыть `parsers/hh.py`
2. Вызвать `fetch_hh("Python", pages=2)`
3. Проверить результат

## Ожидаемый результат

Список вакансий с hh.ru.

## Фактический результат

API возвращает `403 Forbidden`: {"errors":[{"type":"forbidden"}],"request_id":"..."}



## Причина

HeadHunter закрыл публичный API вакансий для неавторизованных запросов (апрель 2026). Метод `GET /vacancies` требует токен работодателя, который выдают только после модерации.

## Обходное решение

Источник hh.ru убран из интерфейса приложения. В качестве альтернативы используется Trudvsem.
