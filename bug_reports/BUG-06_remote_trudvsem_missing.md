# BUG-06 — Trudvsem не отдаёт признак удалённой работы

**Приоритет:** High
**Severity:** Major
**Статус:** Won't Fix (ограничение источника)

## Шаги воспроизведения

1. Собрать вакансии с Trudvsem
2. Поставить фильтр «Только удалённая работа»

## Ожидаемый результат

Список удалённых вакансий.

## Фактический результат

Пустой список.

## Причина

API Trudvsem (`opendata.trudvsem.ru/api/v1/vacancies`) не содержит явного поля `remote`. Информация об удалёнке может быть в поле `employment_type`, но не во всех вакансиях — часто её там нет вовсе.

## Что проверялось

- Поле `schedule` — содержит «Полный день», «Гибкий график», но не «удалён»
- Поле `employment_type` — иногда «Дистанционная (удалённая) работа», но не всегда
- Тексты `requirements` и `job-name` — маркеры удалёнки встречаются редко

## Решение

Оставлено как ограничение источника. Фильтр работает для тех вакансий, где признак есть. В документации приложения указано, что фильтр находит только явно помеченные удалённые вакансии.
